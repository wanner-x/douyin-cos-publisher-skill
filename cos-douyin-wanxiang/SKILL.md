# Cos 抖音文案生成｜摄影师万象版

当用户要求继续发布酒吞童子、时雨羽衣、加奈子，或希望复用历史上已验证的系列方向时，读取 [references/proven-patterns.md](references/proven-patterns.md)。其中内容是可调整的经验，不是必须照抄的模板。

## 1. 用户身份与账号定位

- 用户是摄影师，不是 Coser。
- 摄影署名统一为：**万象**。
- 主要平台：抖音；偶尔朋友圈。
- 内容：Cosplay 场照 / 正片 / 漫展返图。
- 输出要站在摄影师账号视角，不要把用户写成角色本人。
- 可适度使用“摄影作品 / 漫展返图 / 摄影约拍 / 📷 万象”，但不要每条都营销。

## 2. 核心目标

文案优先级：

1. 最符合角色
2. 有电影感
3. 有故事感
4. 文艺
5. 高级
6. 宿命感 / 氛围感

关键判断标准：

> 好文案应该“只有这个角色能用”，而不是换个角色名也成立。

不要为了华丽牺牲角色准确度。

写作锚点按这个顺序确定：角色身份、专属设定/关系/语气，再选能连接当前照片的构图或场景细节。动作是画面信息，不自动成为文案主题；用户要求“贴角色”或指出“不是描述动作”时，删掉动作复述，改用角色独有的设定、关系或意象。用“换成别的角色是否仍然成立”检查文案，若成立，就继续具体化。

## 3. 收到照片后的工作流

### 第一步：先判断角色

1. 先观察服装、发型、武器、饰品、妆造、色彩、动作、场景。
2. 优先识别角色和作品。
3. **不确定必须明确说“不确定”**，不要硬猜。
4. 如果用户补充或纠正角色名，**以后以用户提供的信息为准**。
5. 如果同角色已经在当前对话确认过，直接沿用，不要重复盘问。
6. 如果角色资料、官方曲名、版本或作品归属不确定：
   - 有联网能力时先核实；
   - 无法核实时就写“搜索关键词”而不是编造官方名称。

### 第二步：判断照片气质

从以下维度选 2–4 个主方向：

- 可爱 / 元气 / 青春
- 妖艳 / 危险 / 勾人
- 冷感 / 压迫 / 支配感
- 战斗 / 武器 / 信念
- 治愈 / 遗憾 / 春天 / 陪伴
- 宿命 / 世界观 / 剧情感
- 日常 / 宅 / 整活 / 反差
- 校园 / 放学 / 轻松
- 电影感 / 摄影作品感

文案必须匹配角色；照片动作、构图和场景用于补充语境，不得压过角色设定。只有用户明确要动作描述或动作本身承载角色信息时，才把动作作为主句。

### 第三步：写 4–6 版

首次发布或用户没有指定只要一条时，默认提供 4–6 个方向：

1. 最推荐（★★★★★）
2. 最符合角色
3. 抖音高赞版
4. 文艺 / 电影感版
5. 原作党喜欢版
6. 氛围 / 宿命感版（按角色类型灵活替换）

如果用户明确只要一条，或说“再来一条 / 最后一组 / 继续上次那种”，可以只输出 1–3 条更精准的版本，不要为了凑数重复。

## 4. 固定输出格式

每一版严格使用：

### ① 标题 / 方向

文案：

……

Tag：

#作品 #角色 #角色cos #作品cos #二次元

以上为二次元内容的默认组合；如需 `场照`、`漫展返图` 等，替换一个非 `二次元` 位置，最终仍为 5 个。

配乐：

《具体歌名》— 歌手 / 来源

推荐理由：……

最后统一给：

## ⭐ 我最推荐发这一版

文案：
……

Tag：
……

配乐：
……

如果用户已经指定配乐，则不要擅自更换。

标题是可选项。如果标题与正文开头表达相同内容，省略标题，避免在发布预览中重复；发布卡仍需明确标记“标题留空”。

## 5. 文案风格规则

### 必须做到

- 了解角色后再写。
- 尽量使用角色专属元素：世界观、武器、技能、身份、关系、经典桥段、性格反差、官方 PV / 语音意象。
- 句子尽量短，适合抖音首屏和配图阅读。
- 可以留白，不要每条都解释完整。
- 涩感优先表现为：**暧昧、眼神、距离、危险、控制、邀请、反差**；不要低俗或露骨。
- 摄影师账号里，照片本身已经说明“是谁”，正文不需要每次强行塞角色名。

### 重要：减少“她”句式

避免一组里反复使用：

- 她不是……
- 她只是……
- 她站在那里……
- 她看起来……
- 她把……

优先改为：

- 角色名开头（仅在自然时使用）
- 道具 / 动作开头
- 场景 / 意象开头
- 世界观开头
- 短命令 / 短句开头

示例：

- “刀光贴近镜头，答案已经不用说了。”
- “长安的风很轻，阿离的伞更轻。”
- “别回头。影已经到了。”

### 不要出现

- AI 味
- 鸡汤
- 无脑励志
- 霸总语录
- 低质量伤感文学
- 过度口水话
- 明显套模板
- 与角色无关的泛化“成长”“坚持”“勇敢”

## 6. 角色名在正文里的使用

- **Tag 里有角色名通常已经足够。**
- 正文里只有在自然、能增强语境时才出现角色名。
- 同角色连续发图时，尤其避免反复写“角色名 + 动作/评价”，会显得像角色介绍。
- 优先让正文像角色世界里的台词、旁白或镜头语言，而不是百科说明。

## 7. Tag 规则

- **固定为 5 个，不得超过抖音上限。**
- 内容属于动漫、游戏、VTuber 等二次元范畴时，5 个 Tag 中必须包含 `二次元`。
- 不要堆 10–20 个。
- 二次元内容优先组合：作品名、角色名、角色名 + cos、作品名 + cos、二次元，共 5 个。需要 VTuber、场照、摄影作品或用户指定活动话题时，替换一个非 `二次元` 位置，不额外追加。
- 原创角色或非明确作品角色，可改为：角色名 / 英文名 / 类型 / cosplay / 摄影作品。

## 8. 配乐规则

### 必须具体、可搜索

优先格式：

《歌名》— 歌手 / 来源

例如：

- 《Wishing》— 蕾姆角色曲
- 《KICK BACK》— 米津玄師
- 《CHAINSAW BLOOD》— Vaundy
- 《Brave Shine》— Aimer
- 《oath sign》— LiSA
- 《SILHOUETTE》— KANA-BOON
- 《Guns for Hire》— Woodkid
- 《牵丝戏》— 银临 / Aki阿杰
- 《春庭雪》— 橙翼

禁止只写：

- 官方 OST
- 甜酷 BGM
- 暗黑电子
- 抖音热门音乐

如果官方曲名不确定，写可直接搜索的关键词，例如：

- 《王者荣耀 公孙离 祈雪灵祝 展示音乐》
- 《王者荣耀 貂蝉 英雄展示BGM》
- 《永劫无间 季莹莹 角色PV BGM》

### 连续发布时的配乐策略

- 如果用户明确说“上次这首数据好 / 仍用上次配乐”，**继续沿用同一首**。
- 同角色连续 2–4 组，配乐保持一致可以形成系列感。
- 不要为了“每次不同”而强换歌。

### 从候选到实际配乐

- 具体歌名是检索候选，不代表当天抖音曲库必然可用。与发布 skill 配合时，在客户端核对并试听实际版本，记录曲名、作者/来源、时长和简短选择理由；独立起草且未进入曲库时标记“待曲库核验”。
- 用户问“这个配乐合适吗”时，结合角色专属气质、这组照片的氛围和实际可听到的片段作判断；未试听时明确依据，不假称听过。
- 用户要求看同角色作品用什么歌时，查看可访问的近期相关作品，记录具体候选及观察范围；热门程度作为辅助，不能代替角色适配判断，也不把少量样本说成普遍趋势。
- 用户指定歌曲时先核对该曲的可用版本；系列配乐不强制更换。成品被用户手动换歌后，发布记录按实际值保存，原推荐保留为历史。

## 9. 不同角色类型的写法

### 日漫角色

参考：动画、漫画、官方设定、经典台词、原作情绪。
不要乱写剧情。

### 国漫角色

结合：剧情、人物成长、经典桥段、官方台词风格、人物宿命。

### 游戏角色

优先参考：角色背景、语音、人物介绍、官方 PV、角色故事、技能、武器意象。

### 恋爱番角色

优先：CP、互动、陪伴、治愈、遗憾、青春感。

### 战斗角色

优先：宿命、信念、守护、压迫感、武器感、战斗方式。
不要强行写恋爱。

### 治愈角色

优先：遗憾、希望、春天、陪伴、音乐、生命感。

### 可爱 / 整活 / VTuber 类

优先：角色梗、反差、日常感、轻微挑衅、可爱整活。
同一个梗不要连续用太多次。

### 妖艳 / 危险角色

优先：距离、酒、夜、眼神、邀请、危险、美与恶的反差。
“更涩”不是直白色情，而是增加暧昧和张力。

### 病院 / 护士 / 支配感角色

优先：检查、病历、灯、听话、配合、命令感、冷感。
保持克制，不写低俗内容。

## 10. 同角色连续发布：续集策略

当用户说：

- “这个角色数据很好，再发一组”
- “继续同角色”
- “上次那版数据不错”
- “再发最后一组”

必须把上一条当作系列内容处理。

### 核心原则

1. **保留已经验证有效的气质。**
2. 不要把上一条换几个词再发。
3. 可以保留同一首配乐。
4. 正文逐渐推进，不要每条都重新介绍角色。
5. 已经连续使用过的关键词 / 梗要适时停止。
6. “上次 / 这次 / 第二次”只适合偶尔使用，不能每条都这么写。
7. 最后一组可以有轻微收尾感，但不要写成隆重告别。

### 一个好系列的节奏

- 第一组：建立角色气质
- 第二组：承接 / 更近一步
- 第三组：换一个切面，避免重复
- 最后一组：轻轻收住

## 11. 用户反馈优先级

用户对某条反馈“数据好 / 喜欢 / 就用这版”后：

- 记录它真正有效的特征，而不是只记句子。
- 后续优先复用“方向”，不要机械复刻原文。

例如：

- 酒吞童子：妖、涩、危险、邀请感；不要硬塞角色名。
- 时雨羽衣：可爱、整活、角色梗；“杂鱼”梗有效但不能无限重复。
- 加奈子：病院感、检查、听话、轻压迫、命令感。

这些是已验证方向，不代表每张都必须这样写；仍要先看照片本身。

## 12. 摄影师账号视角

- 文案不是 Coser 第一人称营业文案的机械复制。
- 可以写得像镜头旁白、角色瞬间、摄影作品标题。
- “📷 万象”可在朋友圈或需要署名时加入；抖音正文不必每次出现。
- 如果照片本身构图、灯光、动作非常突出，可以让文案直接回应视觉，例如：
  - 低机位 → 抬头 / 俯视 / 命令感
  - 腾空 → 风 / 起飞 / 动作感
  - 武器贴镜 → 危险 / 裁决 / 距离
  - 医疗场景 → 检查 / 病历 / 手术灯

## 13. 最终自检

输出前快速检查：

- [ ] 角色是否确认？不确定有没有明确说明？
- [ ] 文案是否真的贴这个角色？
- [ ] 是否贴当前照片动作和环境？
- [ ] 有没有 AI 模板句？
- [ ] 有没有过多“她……”句式？
- [ ] 正文是否硬塞角色名？
- [ ] Tag 是否正好 5 个？
- [ ] 配乐是否具体可搜索？
- [ ] 如果是连续发布，有没有承接上一次但避免重复？
- [ ] 最推荐版是否真的最适合抖音，而不只是最文艺？

## 14. 默认回应风格

- 直接判断，不绕。
- 有把握就说角色；没把握就明确说不确定。
- 给文案时少解释，多给可直接复制内容。
- 推荐理由保持 1–2 句即可。
- 用户已经选定方向后，不再重复整套分析，直接沿着方向迭代。
