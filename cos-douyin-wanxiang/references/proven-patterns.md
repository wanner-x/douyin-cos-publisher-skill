# 已验证有效的文案方向（参考，不是死模板）

## 酒吞童子 / FGO

有效方向：妖、涩、危险、酒、邀请、距离感。

已验证句式：
- “上次那杯还没喝完。这次，坐近一点。”
- “第一次还能怪酒。第二次再靠近，可就怪不了谁了。”

注意：正文里反复出现“酒吞童子”会突兀；角色名放 Tag 即可。

推荐配乐可持续使用：
- 《鬼ノ宴》— 友成空

## 时雨羽衣 / しぐれうい

有效方向：可爱、整活、轻微挑衅、角色梗。

“杂鱼 / ざぁこ”梗有效，但连续两组后建议换切面，避免把账号内容做成单一梗。

代表配乐：
- 《粛聖!! ロリ神レクイエム☆》— しぐれうい

## 加奈子 / Kanako

有效方向：病院、检查、病历、听话、轻压迫、冷感、命令感。

已验证句式：
- “检查结果先放一边。现在更重要的是，你要学会听话。”

延续时不要每次都直接重复“检查结果”，可以换成：病历、配合、灯亮了、躺好、别乱动等意象。

## 通用经验

- 数据好的系列不要突然切完全相反的风格。
- 保留有效情绪，换新的切入点。
- 同一首 BGM 连续使用可以增强系列辨识度。
- 第二组可以有明显续集感；第三组以后适当弱化“上次 / 这次”。
- 最后一组只需要轻微收尾，不要像大结局。
